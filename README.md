# COMP3710 Lab Demo 2 — Part 4: Recognition Tasks on OASIS Brain MRI

Two deep learning models trained on the Preprocessed OASIS brain MRI dataset:

- **Task 1** — a convolutional Variational Autoencoder (VAE), with a visualisation of the
  learned latent manifold.
- **Task 2** — a UNet for multi-class brain tissue segmentation, achieving **> 0.9 Dice
  Similarity Coefficient (DSC) on all labels** on the held-out test set.

Both were trained on a single NVIDIA A100 on the UQ Rangpur HPC cluster, submitted via Slurm.

# Task 1 — Variational Autoencoder

## Problem

Learn a compact, continuous latent representation of 2D axial brain MRI slices, such that
new brain images can be generated by sampling from the latent space, and such that moving
smoothly through that space produces smoothly varying anatomy.

## Architecture

**Encoder** — two strided convolutions (64×64 → 32×32 → 16×16, channels 1 → 32 → 64),
flattened into two parallel fully-connected heads producing the latent mean (`mu`) and
log-variance (`logvar`).

**Reparameterisation** — samples `z = mu + eps * std` where `eps ~ N(0, 1)`. This keeps the
sampling step differentiable so gradients can flow back through the encoder.

**Decoder** — mirrors the encoder: a fully-connected layer back to 64×16×16, then two
transposed convolutions (16×16 → 32×32 → 64×64), with a sigmoid output so pixel values
land in `[0, 1]` to match the input range.

**Loss** — binary cross-entropy reconstruction term plus KL divergence against a standard
normal prior. The KL term is what makes the latent space continuous and well-organised
rather than a set of scattered, disconnected codes, which is what makes meaningful
interpolation between points possible.

## Training

- Optimiser: Adam, learning rate 1e-3
- Batch size: 64, images resized to 64×64
- Epochs: 40

Two models are trained: a 16-dimensional latent model (used for the reconstruction
comparison) and a separate 2-dimensional latent model, so the latent space can be swept
and rendered directly as a 2D grid of decoded images.

## Results

**Convergence** (`part4_loss_curve.png`): train loss 1213 → 1036, validation loss 1107 → 1053
over 40 epochs, plateauing around epoch 30. Train and validation losses track closely
throughout, indicating the model generalises rather than memorising the training slices.

**Reconstructions** (`part4_reconstructions.png`): ventricular structure, skull outline and
overall brain shape are reproduced accurately. Fine cortical texture is smoothed — the
expected blurriness of a VAE, arising from the tradeoff between the reconstruction and
KL terms in the loss.

**Latent manifold** (`part4_manifold.png`): decoding a 12×12 grid over the 2D latent space
produces brain slices that vary smoothly and continuously in both directions, with ventricle
shape and overall slice appearance morphing gradually rather than jumping between unrelated
images. Samples far from the latent origin (upper-right of the grid) degrade into noise,
since the KL prior concentrates the training encodings near the origin and the decoder is
extrapolating beyond the region it saw during training.

# Task 2 — UNet Segmentation

## Problem

Segment each MRI slice into the four tissue classes above, using categorical (one-hot)
output, and validate that every class exceeds 0.9 DSC on unseen data.

## Architecture

A standard UNet with four encoder stages, a bottleneck, and four decoder stages.

**Encoder** — each stage is a `DoubleConv` block (two 3×3 convolutions, each followed by
batch normalisation and ReLU), followed by 2×2 max pooling. Spatial size halves and
channel depth doubles at each stage: 256×256 → 128 → 64 → 32, channels 32 → 64 → 128 → 256.

**Bottleneck** — `DoubleConv` at 16×16 with 512 channels.

**Decoder** — mirrors the encoder using transposed convolutions to upsample. At each stage
the upsampled feature map is **concatenated with the matching encoder feature map (skip
connection)** before the `DoubleConv`. The skip connections restore fine spatial detail
that is lost during downsampling, which is what makes precise boundary delineation
possible — without them, the decoder would have to reconstruct boundaries from
heavily-compressed features alone.

**Output** — a 1×1 convolution producing 4 channels, one per class. Softmax over the
channel dimension gives a categorical (one-hot) output; `argmax` gives the predicted class
index per pixel.

**Loss** — cross-entropy plus soft Dice loss. Cross-entropy handles per-pixel
classification, while the Dice term directly optimises the metric being reported, which
particularly helps the smaller classes such as CSF where pixel counts are heavily
imbalanced against the background.

## Training

- Optimiser: Adam, learning rate 1e-3, cosine annealing schedule
- Batch size: 16, images at full 256×256 resolution
- Epochs: 20
- Mixed precision (`autocast` + `GradScaler`)
- Training time: 922 seconds on one A100

Masks are resized with **nearest-neighbour** interpolation rather than bilinear — bilinear
would interpolate between label values (producing e.g. 127 between 85 and 170) and corrupt
the ground truth.

Model selection: the checkpoint with the best mean validation DSC is kept (best mean
validation DSC 0.9754), and that checkpoint is evaluated once on the held-out test set.

## Results

Final held-out test set DSC:

| Class | DSC | > 0.9 |
|---|---|---|
| Background | 0.9993 | ✔ |
| CSF | 0.9578 | ✔ |
| Grey matter | 0.9651 | ✔ |
| White matter | 0.9790 | ✔ |
| **Mean** | **0.9753** | |

**All labels exceed the 0.9 DSC requirement.**

CSF scores lowest of the four, which is expected: it forms the thinnest and smallest
structures in the image, so boundary pixels make up a larger fraction of the class total
and small misalignments cost proportionally more.

**Training curves** (`unet_training_curves.png`): loss falls from 0.287 to 0.032; all four
per-class validation DSC curves sit above the 0.9 line from the first epoch onward and
converge smoothly.

**Qualitative results** (`unet_segmentation_results.png`, `unet_live_demo_output.png`):
predicted segmentations are visually near-indistinguishable from the ground truth masks,
with accurate ventricle and grey/white matter boundaries.

**Live inference** (`unet_live_demo.py`): loads the trained checkpoint and segments
randomly-selected slices from the held-out test set, reporting per-slice per-class DSC.
Representative per-slice mean DSC values: 0.9736, 0.9695, 0.9796, 0.9797.

## Running

On Rangpur:

```bash
conda activate torch

# Task 1
sbatch vae_job.sh

# Task 2
sbatch unet_job.sh

squeue --me
```

Live inference demo (interactive GPU session):

```bash
srun --partition=comp3710 --gres=gpu:1 --time=00:15:00 --pty bash
conda activate torch
python3 unet_live_demo.py
```

Locally (CPU, for prototyping): edit the dataset path variables near the top of either
script to point at a local copy of the dataset. `OASISSliceDataset` and `OASISSegDataset`
both accept a `limit=` argument to use a small subset for quick sanity checks.
